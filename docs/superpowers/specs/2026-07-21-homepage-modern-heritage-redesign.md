# 华韵非遗首页现代化改版设计规格

## 目标

将首页改造成面向年轻用户的现代非遗探索平台。视觉参考已确认的浏览器预览方案：暖白宣纸质感背景、左侧品牌主张、右侧非遗主视觉与窄幅分类轨道，强调真实工艺图片、材料质感和文化温度。

本次只改首页展示层和首页组件，不修改 CMS、Supabase 表结构、飞书同步、内容接口或后台管理功能。

## 已确认视觉方向

- 网站名称：华韵非遗。
- 主标题固定两行，无标点：`让千年技艺` / `被世界看见`。
- 主标题下保留简短说明，不显示 Hero 行动按钮。
- 暖白、低饱和背景，带极轻的纸张纹理。
- 不使用深色展厅、NFT 展示、编号体系或普通商品卡片墙。
- 顶部导航包含：首页、传承文化、非遗项目、注册、登录、联系我们。
- 右侧以一张固定主视觉和三条窄幅视觉轨道组成；轨道悬停时只展开图片，不切换主图，不展示项目名称、地域、分类或简介。
- 不使用鼠标跟随放大镜。
- 图片加载失败时保留稳定尺寸和中性背景，不让布局塌陷。
- Hero 底部使用一句简洁的品牌价值表达收束。

## 页面结构

### 1. 首页导航

复用项目现有国际化路由和链接组件。桌面端为品牌、居中导航、右侧账户与联系入口；移动端继续使用现有移动菜单模式。

导航目标：

- 首页：`/`
- 传承文化：`/museum`
- 非遗项目：`/heritage`
- 注册、登录：`/login`
- 联系我们：页面内合作入口或现有联系锚点

### 2. Hero 工艺探索

桌面端采用约 `35% / 65%` 的左右布局。

左侧：

- 英文眉题。
- 两行中文品牌主张。
- 一段平台说明。
- 不显示行动按钮。

右侧：

- 主视觉占右侧绝大部分宽度。
- 三条窄幅分类轨道位于主视觉右侧。
- 默认主视觉从 CMS 精选项目中选择，优先使用具备高质量图片的项目。
- 三条轨道从其他具备高质量图片的项目中选择，仅作为视觉探索入口。
- 悬停或键盘聚焦轨道时只展开对应轨道图片，不改变固定主视觉。
- 点击主视觉或轨道进入对应非遗详情页，画面内不叠加项目元数据。
- 交互对键盘可用，并遵守 `prefers-reduced-motion`。

### 3. 合作入口

页面尾部保留简洁的咨询合作入口，与顶部“联系我们”联动。不得新增后端表单或数据接口。

## 组件结构

```text
app/[locale]/page.tsx
└── HomeCmsContent
    ├── HomeHeader
    │   └── HomeMobileMenu
    ├── HeritageExplorerHero
    │   ├── HeroBrandCopy
    │   ├── HeritageMainVisual
    │   └── HeritageVisualRails
    └── HomeContactEntry
```

`HomeCmsContent` 仍负责等待 `getHeritageItems()` 并将数据传入首页展示组件。交互式主视觉组件使用客户端组件，但页面和数据获取继续保持服务端边界。

## 数据映射

- 数据来源保持 `getHeritageItems()`，不新增首页专用 API。
- 主视觉和轨道只使用 `image || heroImage` 作为画面内容。
- 链接使用现有 `slug` 进入 `/heritage/[slug]`。
- 数据不足时使用项目现有静态非遗资产作为展示兜底。
- 图片字段为空或加载失败时显示固定比例的中性色背景和项目名称，不改变网格尺寸。

## 响应式行为

- 桌面端：左右 Hero，主视觉加三条分类轨道。
- 平板端：保持左右关系，但缩小标题和轨道宽度。
- 移动端：文案在上，主视觉在下；分类轨道改为可横向浏览的稳定宽度项目，不执行遮挡式展开。
- 所有标题固定在容器内换行，不出现水平溢出。
- 导航在移动端进入现有菜单，不显示传承故事入口。

## 动效

- 页面进入时使用轻微淡入和上移。
- 分类轨道悬停时展开对应图片，固定主视觉不切换。
- 主视觉仅在自身悬停时进行轻微缩放。
- 禁止跟随鼠标的圆形放大镜。
- 减少动态偏好下关闭位移和缩放。

## 验证标准

- CMS、飞书同步、Supabase 和后台相关测试保持通过。
- 首页仍只从现有内容仓储读取数据。
- `npm test`、`npm run typecheck`、`npm run build` 通过。
- 在 1440px、390px 视口检查首页，无水平溢出、文字遮挡或图片塌陷。
- 使用键盘可聚焦并展开视觉轨道。
- 模拟图片加载失败时，Hero 与分类导航尺寸保持稳定。

## 范围外

- 不修改 CMS 字段、数据库表或接口。
- 不修改飞书同步逻辑。
- 不新增注册、登录或联系后端功能。
- 不重做非首页页面。
- 首页不展示独立分类探索、精选内容或传承人内容模块。
