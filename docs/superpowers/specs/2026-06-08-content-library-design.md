# Content Library V1 Design

## Goal

Build the first production content library for HuaYun ICH:

- 100 heritage projects
- 1,000 images
- 200 videos

The first phase prioritizes complete structured records over perfect media coverage. Media can be marked as authorized, placeholder, or external while the editorial team gradually replaces placeholders with licensed assets.

## Recommended Strategy

Use a hybrid editorial model:

1. Create complete structured profiles for 100 heritage projects.
2. Require every project to have enough metadata to render all public pages.
3. Allow media records to carry a rights and source status.
4. Publish only items that pass editorial and rights review.
5. Reindex AI assistant documents after each approved content batch.

This keeps the site growing without waiting for all photography and video licensing to finish.

## Data Model Additions

The current core tables remain valid:

- `categories`
- `heritage_items`
- `heritage_media`
- `media_assets`
- `inheritors`
- `assistant_documents`

Add production content governance fields through a new migration.

### heritage_items

Add:

- `content_status text`: `draft`, `review`, `published`, `archived`
- `editorial_priority integer`: higher values surface first in editorial queues
- `source_notes text`: short source summary for editors
- `rights_notes text`: rights status summary
- `reviewed_at timestamptz`
- `reviewed_by text`

Keep `published boolean` for existing public reads. `published = true` only when `content_status = published`.

### media_assets

Add:

- `source_type text`: `uploaded`, `external`, `placeholder`
- `source_url text`
- `credit text`
- `license text`
- `rights_status text`: `pending`, `cleared`, `restricted`, `rejected`
- `reviewed_at timestamptz`
- `reviewed_by text`

Public pages should prefer assets with `rights_status = cleared`, but may show placeholder assets for draft/admin views.

### inheritors

Add:

- `english_name text`
- `region_notes text`
- `source_notes text`
- `rights_notes text`

## Import Workflow

1. Editors prepare project records in a CSV or JSON batch.
2. Validation script checks required fields, slugs, category references, province names, related slugs, and media rights fields.
3. Import script upserts categories, heritage items, inheritors, and media metadata.
4. Uploaded files continue to use the existing CMS and Supabase Storage upload flow.
5. External media records store URLs and source metadata.
6. Placeholder media records point to local placeholder assets or curated generated placeholders.
7. Admin reviews the batch in `/admin`.
8. Approved records are marked `content_status = published` and `published = true`.
9. AI assistant index is regenerated.
10. Sitemap is regenerated by the Next.js route at build or runtime.

## Rights Policy

Production content must distinguish three states:

- `cleared`: can be shown publicly.
- `pending`: visible in admin only.
- `restricted`: recorded for editorial reference but not shown publicly.

External media should not be copied into Supabase Storage unless usage rights are clear. Public pages may link or embed external media only when the provider terms allow it.

## CMS Requirements

The existing CMS remains the management surface, with future additions:

- Content status filter
- Editorial priority filter
- Rights status filter in media library
- Source and credit fields in media editor
- Batch import preview
- Missing media report
- AI reindex button after batch publication

## Public Display Rules

List and detail pages should continue reading from Supabase.

Display preference:

1. Cleared uploaded media
2. Cleared external media
3. Placeholder media only when no cleared media exists and the project is intentionally published with placeholder coverage

Every image should have alt text. Every visible media asset should display credit or keep credit available for a future rights panel.

## Quality Gates

A project can be published when:

- Required fields are complete
- Category and province are valid
- At least one cover or hero visual exists
- Public media assets are cleared or intentionally marked placeholder
- Summary, history, and timeline pass editorial review
- English name exists
- AI assistant documents can be generated
